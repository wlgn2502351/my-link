## 3. 영역별 상세 명세 (Component Annotations)

### `[1]` 상단 고정 Topbar (`header`)
- **좌측**: 브랜드 이니셜 아바타(`JH`, `28×28px` 원형 `--brand-default`) + 크리에이터 이름(`김지후`) + 구분선 + 서브라벨(`Creator Profile`)
- **우측 (방문자용 컨트롤)**:
  - **상태 뱃지** (`sm` 이상 노출): 녹색 상태 점(`●`) + 현재 상태 텍스트(`바이브 코딩 집중 주간`)
  - **라이트/다크 모드 수동 토글 버튼 (`☀️/🌙`)**: `36×36px` 원형 아이콘 버튼. 클릭 시 `localStorage("mylink_theme")` 저장 및 라이트/다크 컬러 토큰 즉시 전환
  - **주요 문의 CTA 버튼 (`문의하기`)**: `36px` 높이 캡슐형(`rounded-[50px]`) 프라이머리 버튼 (`mailto:` 또는 지정 링크 연결)

### `[2]` 메인 프로필 카드 (좌측 5컬럼 상단)
- **카드 헤더**: 아이콘 + `크리에이터 프로필` 라벨 / 우측 `ACTIVE 2026` 뱃지
- **배너 영역**: `160px~180px` 커버 이미지 + 하단 그라데이션 오버레이 + 좌상단 `CREATIVE STUDIO` 캡슐 뱃지
- **아바타 & 타이틀**: 배너 하단에 걸쳐 올라오는(`-mt-[48px]`) 원형 아바타(`96px~104px`) + 우측 `VIBE CODER` 뱃지 + 직군 뱃지 + 한글/영문 이름
- **자기소개 박스**: `--background-subtle` 배경의 라운드 박스(`16px`) 안에 소개글 본문 배치
- **3단 요약 지표**: `ROLE` / `FOCUS` / `GROWTH` 3열 그리드 (`divide-x` 구분선, 수치에 `.tabular-nums` 적용)
- **하단 듀얼 CTA 버튼**:
  - 좌측(`작업물 살펴보기`): `#channels` 섹션으로 부드럽게 스크롤 이동하는 Primary Pill 버튼
  - 우측(`협업 제안하기`): 이메일/연락처로 연결되는 Outline Pill 버튼

### `[3]` 디자이너 노트 카드 (좌측 5컬럼 하단)
- 전구 아이콘 + `DESIGNER NOTE` 타이틀 + 우측 `Manifesto` 서브라벨
- 크리에이터의 작업 철학/문구를 보여주는 인용구 카드

### `[4]` 보유 역량 및 학습 현황 (`01 · TOOLKIT & PROGRESS`)
- **섹션 헤더**: `01 · TOOLKIT & PROGRESS` + `보유 역량 및 학습 현황` 타이틀 + 우측 `DESIGN × CODE` 뱃지
- **스킬 Pill 리스트**: 5가지 시맨틱 톤(`red`, `teal`, `green`, `blue`, `neutral`)이 적용된 캡슐형 태그 목록 (호버 시 미세 상승 인터랙션 `hover:-translate-y-0.5`)
- **진행률 서브 카드**: `진행 중` 뱃지 + 프로젝트 제목 + 우측 큰 퍼센트 수치(`85%`, `.tabular-nums`) + `10px` 높이 캡슐형 프로그레스 바 + 하단 부연 설명

### `[5]` 포트폴리오 및 소통 채널 (`02 · CHANNELS & ARCHIVES`)
- **섹션 헤더**: `02 · CHANNELS & ARCHIVES` + `포트폴리오 및 소통 채널` 타이틀 + 우측 활성 링크 수(`총 N개 채널`, `.tabular-nums`)
- **채널 링크 카드 그리드** (모바일 1열, 태블릿/데스크톱 2열):
  - `isActive === true`인 카드만 방문자 화면에 노출
  - **카드 상단**: 좌측 원형 프리셋 SVG 아이콘(`36×36px`) + 우측 카테고리 뱃지(`PORTFOLIO`, `SOCIAL`, `CODE LAB`, `CONTACT`)
  - **카드 본문**: 일련번호 및 영문 라벨(`01 · BEHANCE ARCHIVE`) + 한글 제목 + 2줄 내외 설명 문구
  - **카드 하단 푸터**: 상단 보더로 구분된 액션 라벨(`작업물 보러가기` 등 `--interaction-blue` 컬러) + 우측 화살표 아이콘 (`group-hover:translate-x-0.5` 인터랙션)

### `[6]` 하단 푸터 & 조용한 편집 모드 진입 버튼 (`footer`)
- **좌측**: `CREATOR` 뱃지 + 저작권 문구 (`© 2026 김지후 (Kim Ji-hoo). All rights reserved.`)
- **우측**: 디자인 시스템 메타 텍스트(`Stack Tokens v2.6 · Pretendard Variable`) 옆에 방문자 시선을 방해하지 않는 작고 차분한 **`[⚙️ 편집]` 토글 버튼** 배치
  - 클릭 시 페이지 상단에 편집 컨트롤 바(`저장하기` / `취소` / `초기값 리셋`)가 나타나며 인라인 편집 모드로 전환됨
